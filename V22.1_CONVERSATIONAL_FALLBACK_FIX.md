# V22.1 — Conversational fallback fix

## Problem
When the Supabase/OpenAI gateway was unavailable, the local fallback returned a generic phase brief for unrelated questions. This made every user question receive the same ACCUMULATION sentence.

## Fix
The local fallback now runs the Coach agent and routes the question through intent-aware deterministic analysis. It can answer phase, hypertrophy volume, goal priority, recent workout decisions, RIR/fatigue, and modification questions using current app context.

The gateway still prefers the server-side OpenAI Responses API when Supabase is configured. The local fallback is not an LLM; it is a data-grounded safety fallback.
