# V22.7 — Real Test Baseline

This is the final implementation pass before real athlete validation.

## Scope
- Separate planned weekly hypertrophy exposure from performed productive exposure.
- Proposal impact now reports per-muscle hypertrophy delta.
- Proposal impact explicitly reports protection/watch status for OAP, FL Pull-Up and Front Lever Touch.
- Keep AI conversational layer and deterministic engine separation intact.

## Athlete test contract
The athlete should log only the data needed for decisions:
- reps/hold result
- RIR where useful
- quality for priority skills
- session fatigue at the end
- readiness when relevant

## Coach validation
The Coach must:
1. use real logged data for claims about performance/volume;
2. distinguish planned volume from completed productive volume;
3. avoid progressing a skill on one anomalous exposure;
4. protect OAP, FL Pull-Up and Front Lever Touch when adding secondary volume;
5. produce a concrete proposal before changing programming;
6. keep proposal changes single-variable and reversible.

## Important limitation
The planned-volume calculation is an internal planning proxy, not a physiological measurement. EMOM minutes are treated as work-interval units for planning; they are not claimed to equal conventional hypertrophy sets one-to-one.
