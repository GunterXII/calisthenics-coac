# V18.1 — OAP clarity + valid zero-rep logging

- OAP Thursday is explicitly **6 quality sets**, not 6–8 attempts.
- Skill wording now uses **sets** rather than attempts.
- Standard rep sets accept **0 reps** as a valid performance/fatigue datapoint.
- Side-based skill sets accept **0 reps** as well.
- Editing an already logged set can change it to 0.
- Zero-rep sets are preserved in logs instead of being treated as missing data.
