# Calisthenics Coach — UX refinement

## Daily mission
Today now derives its primary mission from the day program's `priority: "primary"` block.

Primary blocks:
- Monday: Pike Push-up
- Tuesday: Front Touch
- Wednesday: Push-up EMOM
- Thursday: One Arm Pull-up
- Friday: Push-up Long Set
- Saturday: Full Front Lever Pull-up
- Sunday: Broad Jump

## Targets
Workout logging now distinguishes:
- **TODAY** — the concrete target to execute in this exposure.
- **COACH RANGE** — the broader prescription/range for the current training level.

## Workout player
The player is intentionally minimal:
- icon-only sound/haptic/exit controls
- exercise title + previous result only
- compact prescription panel
- no redundant explanatory labels
- explicit `LOG 0 REPS` action for rep-based blocks
- explicit `LOG 0` action for EMOM minutes

## Coach handoff
The copied report now contains:
- readiness
- plan priority
- coach range vs today target
- actual execution
- previous exposure and delta
- RIR/fatigue/band/side data
- signal (progress / hold / recovery / drop-off / reset)
- concrete suggested plan edit
- explicit coach decision checklist
