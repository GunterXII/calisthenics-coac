# V15.4.1 Personal Coach Polish

Focused on the original single-athlete/parchetto workflow.

## Changes
- Improved the end-of-workout **Coach Handoff** report.
- Added readiness context to the handoff (energy, sleep, pain, bodyweight when available).
- Added previous-exposure comparison for reps, holds and EMOM totals.
- Included band, RIR, fatigue, incomplete/modified status and relevant session notes.
- Fixed the copy action so the current session-feel/note is included even before saving feedback.
- Made the primary end-of-session action explicitly **COPY FOR COACH**.
- Kept the full report available as an optional detail/export view.

## Scope
No general-purpose workout-engine rewrite was introduced. The app remains focused on the personal calisthenics/parchetto workflow and external coach review.
