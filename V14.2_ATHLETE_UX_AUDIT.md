# Calisthenics Coach V14.2 — Athlete UX Audit

## Fixed
- Removed remaining `.at()` usage from the V14 baseline.
- Removed duplicated backend sync guard.
- Program Editor changes now trigger best-effort Supabase program sync immediately.
- Program reset / progression promote / hold actions now also create or sync coach decisions.
- Reset-all program changes sync to the backend.
- Post-workout mobility timers use timestamp-based countdowns instead of decrement-only intervals.
- Mobility session duration is measured from the start of the mobility phase and is no longer reset on every exercise.
- Mobility dynamic exercises now have a visible timer plus a rep counter, matching the requested athlete UX.
- Added confirmation before SKIP ALL mobility.
- Guarded mobility completion against double-submit / timer + button race conditions.
- Mobility final exercise returns cleanly to the workout summary after logging.

## Deliberately not changed
- Workout engine architecture remains intact.
- No large refactor of `main.tsx` in this pass; stability is prioritized over churn.
- No push-notification implementation yet.
- No new Supabase migration was needed in this pass; the mobility schema already exists in the connected project.
