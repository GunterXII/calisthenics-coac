# Phase 4 — Programming Calibration

Updated the weekly program after the 4-workout beta using the observed performance, recovery and exercise-context feedback.

## Programming decisions
- Keep EMOM as the main density tool for the push/pull volume work, but use sustainable targets and stable output as the progression signal.
- Keep skill work first and give OAP / Front Lever work long recoveries.
- Reduce redundant high-volume straight-set work so weekly push/pull volume is recoverable while preserving enough hypertrophy exposure.
- Increase accessory/core recoveries to 120s+ where grip or local fatigue was limiting performance.
- Replace Pull B Hanging Leg Raise with floor/bench-based Dragon Flag to avoid adding grip demand after pulling work.
- Default Assisted OAP and Assisted FL Pull-up to the Red 50–125 lb band based on the beta feedback; progression to lighter assistance requires clean reps across the prescribed range.
- Keep long-set work on Friday as a fun performance target, but do not treat it as a weekly max.
- Preserve the 6-day Push/Pull rhythm and Sunday athletic lower-body maintenance day.

## Current EMOM baselines
- Push-up EMOM: 10–12/min
- Dips EMOM: 6–8/min on Wednesday, 7–9/min on Friday
- Close-Grip Chin-up EMOM: 5–7/min
- Close-Grip Pull-up EMOM: 5–7/min

The ranges are intentionally broader than a single hard target. The Coach should progress only after stable, repeatable output with appropriate RIR and recovery.
