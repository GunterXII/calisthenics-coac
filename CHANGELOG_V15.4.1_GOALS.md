# V15.4.1 — Pull-focused goal correction

- Removed Handstand 30-Day Tutorial from Monday PUSH A. The program no longer prioritizes handstand practice.
- Pull-up EMOM baseline recalibrated to **5–7 reps/min**. Progression intent: establish 5/min with consistent ROM, then 6/min, then 7/min.
- Close-Grip Chin-up and Close-Grip Pull-up progression ceilings aligned to **7/min** with stable ROM.
- Pull skill priority remains on the programmed pull skill work (Front Touch, One-Arm Pull-up, Full Front Lever Pull-up) plus strength/volume support.
- Existing push-up and dip work is intentionally unchanged in this patch; the long-term performance goals are 100 push-ups and 50 dips and should be handled as measurable progression goals rather than by inflating every workout target immediately.
