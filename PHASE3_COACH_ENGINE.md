# Phase 3 — Coach Engine

Implemented: context-aware exercise decisions using prescription ranges, RIR, fatigue, readiness gates, EMOM stability and comparable-exposure matching.

Decision model: PROGRESS / HOLD / REGRESS / REDUCE_VOLUME / REVIEW. Upper-range progression now requires the upper prescription boundary, stable EMOM output when applicable, adequate RIR/readiness, and the existing consecutive-exposure gate. A single hard session does not cause an automatic regression; recovery/pain signals drive conservative decisions. Historical comparisons are restricted to the same prescription snapshot when available.
