# V14.3.1 — Stable Fix

This release rolls back the fragile V14.3 screen split introduced in `secondary.tsx`.

## Why
The split duplicated symbols and separated components from the constants/helpers/imports they depend on, causing TypeScript failures (`App`, `Metric`, `DAYS`, `LABEL`, sync helpers, etc.).

## Strategy
- Restore the proven V14.2 monolithic `src/main.tsx`.
- Keep the V14.2 mobility/backend improvements.
- Keep repository hygiene via `.gitignore`.
- Keep conservative dependency-only Rollup chunks in `vite.config.ts`.

## Rule
Do not attempt another component split until it is done incrementally with explicit exports/imports and a build after each boundary is moved.
