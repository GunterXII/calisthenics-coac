# V15.1 — Skill Intelligence

## Added
- Exercise-specific Skill Intelligence engine.
- Consecutive qualifying-session logic: one qualifying exposure = HOLD; two consecutive = PROGRESS candidate.
- Conservative REGRESS / REVIEW paths using pain, performance drop, readiness and static quality.
- Confidence and data-quality indicators.
- Next-variant recommendation surfaced from the progression ladder.
- Premium Skill Intelligence panel in Coach Workspace.
- Decision Center now consumes Skill Intelligence recommendations.

## Design rule
The engine recommends; the human coach decides. No automatic program promotion is performed.

## V15.2 — Skill Graph Intelligence
- Added prerequisite-aware Skill Graphs for Planche, Front Lever, OAP, Muscle-up and HSPU.
- Graphs are catalog-driven and show the current rung, next mechanical rung and pathway completion.
- Graph recommendations remain advisory; Skill Intelligence + human Coach decision remain the promotion gate.
- Avoids treating raw difficulty as a sufficient progression rule.
