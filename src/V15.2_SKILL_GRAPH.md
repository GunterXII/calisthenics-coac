# V15.2 — Skill Graph Intelligence

## Goal
Turn the exercise catalog into a prerequisite-aware skill roadmap rather than a flat list of harder exercises.

## Principles
1. A harder exercise is not automatically the correct next exercise.
2. Mechanical prerequisites are explicit.
3. The graph suggests a next rung; it never auto-promotes the athlete.
4. Skill Intelligence remains the evidence gate using quality, readiness, RIR, pain and consecutive qualifying exposures.
5. Coach Decision Center remains the final authority.

## Graphs
- Planche: lean → tuck → advanced tuck → straddle → full
- Front Lever: tuck → advanced tuck → one-leg → straddle → full → front touch
- OAP: archer → assisted OAP → negative → isometric → strict OAP
- Muscle-up: chest-to-bar → high pull → transition → negative → strict muscle-up
- HSPU: wall handstand → pike → feet-elevated pike → wall HSPU → deficit wall HSPU → freestanding HSPU

## Safety / product rule
The graph does not prescribe training by itself. It provides the Coach with a transparent roadmap and prevents arbitrary catalog swaps.
