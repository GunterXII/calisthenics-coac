# V15 — Athlete Performance Dashboard

Adds a premium coach-facing performance snapshot built from the athlete's real session and exercise log data.

## Metrics
- exercise exposures from recent sessions
- total logged reps across the last 6 sessions
- average readiness energy and sleep
- maximum reported elbow/wrist load
- skill leaders from the existing athlete timeline
- current Coach Intelligence signals

## Design rule
The dashboard is decision support only. It never changes the athlete's program automatically.
